🍕 Pizza Sales Dashboard (Excel)
📊 Overview

Project ini merupakan dashboard analisis penjualan pizza yang dibuat menggunakan Microsoft Excel.
Dashboard ini digunakan untuk menganalisis performa penjualan, pola pembelian, serta tren produk.

Untuk memastikan keakuratan data, seluruh perhitungan pada dashboard divalidasi menggunakan query SQL yang disertakan dalam laporan validasi.

🚀 Cara Menggunakan
1. Membuka Dashboard
Masuk ke folder data/
Buka file: Porto_da.xlsx
Pilih sheet bernama "Dashboard"

Pada sheet ini terdapat berbagai visualisasi, seperti:

Total Revenue
Total Orders
Average Order Value
Tren penjualan harian & per jam
Analisis kategori dan ukuran pizza
Produk terlaris dan tidak terlaris

2. Mengecek Keakuratan Data 🔍

Untuk memastikan bahwa data pada dashboard sudah benar:

Masuk ke folder docs/
Buka file: SQL_Validation_Report.docx

Isi dari file tersebut:

Query SQL untuk setiap KPI
Hasil output query (berupa screenshot)
Pembuktian bahwa hasil query sesuai dengan dashboard

👉 Dengan ini, dashboard tidak hanya visual, tapi juga terverifikasi secara data.

📁 Struktur Project
data/ → File Excel (dataset & dashboard)
docs/ → Laporan validasi SQL (Word)
images/ → Preview dashboard

🧠 Insight yang Dianalisis
Performa pendapatan (revenue)
Pola jumlah order berdasarkan hari dan jam
Kontribusi penjualan berdasarkan kategori dan ukuran
Identifikasi produk paling laris dan paling sedikit terjual

🛠 Tools yang Digunakan
Microsoft Excel (Dashboard & Visualisasi Data)
SQL (Validasi dan perhitungan data)

📌 Catatan
Project ini menunjukkan bagaimana dashboard Excel dapat dikombinasikan dengan SQL untuk menghasilkan analisis yang tidak hanya informatif tetapi juga akurat dan dapat dipercaya.
